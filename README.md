# 英文單字複習小幫手（親子共學 Web App）

免登入、純靜態、可直接於手機與桌面瀏覽器使用的英文單字複習網站。

## 核心功能

- **多組課次管理（IndexedDB 本機儲存）**：每個單字組獨立儲存於瀏覽器，重新整理或關閉重開後可直接選用。
- **匯入與共用可編輯預覽**：
  - 上傳 UTF-8 `.txt`（每行一個英文詞）
  - 手機拍照辨識（瀏覽器端 Tesseract.js Web Worker，不需後端）
  - 獨立的相簿／檔案選圖入口與手動貼上文字
  - 失敗、空檔或寫入錯誤皆保留現有預覽內容
- **單字組詳情與配圖管理**：
  - 修改組名、增刪與排序詞條
  - 修改詞條拼寫時自動要求重新確認既有配圖
  - 跨單字組重用已確認配圖（同詞同詞義優先推薦，資料庫僅存一份）
  - 支援設定抽象詞情境圖與「易混淆干擾詞排除」
- **三種複習模式**：
  - **字母填空**：保留空格與連字號，只挖英文字母；單字母詞留給其他模式；2–3 字母挖 1 格；長詞挖約 1/3 且每個空格/連字號片段至少留 1 個可見字母。
  - **聽音拼字**：使用瀏覽器 `speechSynthesis`，優先選擇裝置本機英文語音，支援重播、慢速播放與失敗重試。
  - **看圖選字**：以家長確認的配圖出題，提供正解與最多 3 個同組不重複、非易混淆干擾項（至少 2 選項）。

## 本機開發與在手機上直接使用

```bash
npm install
npm run dev
```

啟動後，終端機會顯示本機網址（如 `http://localhost:5173`）以及**區域網路網址（如 `http://192.168.x.x:5173`）**。
只要手機與電腦連上同一個 Wi-Fi，在 iPhone Safari 或 Android Chrome 開啟該區域網路網址即可直接體驗；也可執行：

```bash
npm run build
```

將產出的 `dist/` 靜態資料夾部署至 GitHub Pages、Netlify、Vercel 或 Cloudflare Pages，隨時在手機瀏覽器打開（並可「加入主畫面」當作 App 使用）。
